Every Claude Code session, every device, one stream

Braid copies your Claude Code history from all your machines to a server you run. You get one timeline, a live view and your numbers, and nothing gets lost.

curl -fsSL https://get.usebraid.dev | sh

Installs braid to ~/.local/bin after it checks the SHA-256 sum. No sudo. On Windows, install with Scoop.

What you get

See your work

One timeline
All sessions from all devices. Filter by device, project, model, skill and time.
Live view
Running sessions as they happen, subagents included.
Session canvas
Open a session as a graph of the main session, its subagents and skill phases.
Your numbers
Sessions, active agent time, cost, tokens and streak over your whole history.
Failures
Usage limits, rate limits, server errors, refusals and failed tool calls: how often, why, and the time they cost.
Band
A band in Claude Code shows the current session and today across all devices.

Keep it yours

Nothing lost
The raw transcript lines are kept as they are. Everything you see is derived from them and can be rebuilt.
No token cost
Braid reads files on disk. It never calls a model.
Your server
Your machine, your Postgres. Every user sees only their own data; admins see totals.
Your login
Sign in with Pocket ID, Authentik, Keycloak, Authelia, Zitadel or any other OIDC provider.

How it works

  1. A daemon on each device

    It watches the Claude Code files and sends new lines to your server. When a device was offline, it catches up.

  2. Your server keeps everything

    The raw lines go into Postgres. Sessions, cost and failures are derived from them.

  3. You look at it

    Open the dashboard in a browser, or glance at the band in Claude Code.

Run your own server

The server is one container next to Postgres, built for amd64 and arm64. The quick start brings it up with Docker Compose and a login provider in a few minutes.

docker pull ghcr.io/usebraid/braid-server:latest

Releases and images are signed with cosign. Verify a release.

Built on agents-observe and ponytail. The board look and parts of the code come from ponytail, the idea of syncing sessions from agents-observe.
