Every Claude Code session, every device, one stream

Braid copies your Claude Code history from all your machines to a server you run. You get one timeline, a live view and your numbers. Nothing is lost.

curl -fsSL https://get.usebraid.dev | sh
brew install usebraid/tap/braid

The script checks a SHA-256 sum before it installs anything. More install options.

{{shots}}

What you get

  • One timeline

    All sessions from all devices. Filter by device, project, model, skill and time.

  • Live view

    See running sessions as they happen, subagents included.

  • Session canvas

    Open a session as a graph: main session, subagents and skill phases.

  • KPIs

    Sessions, agent time, cost, tokens and streak over your whole history.

  • Failures

    Usage limits, rate limits, server errors, refusals and failed tool calls. How often, why, and how much time they cost.

  • Band

    A band in Claude Code shows the current session and today across all devices.

  • Nothing lost

    The raw transcript lines are kept as they are. The dashboard is derived from them and can be rebuilt.

  • No token cost

    Braid reads files on disk. It never calls a model.

  • Self-hosted, any OIDC

    Your server, your database. Sign in with Pocket ID, Authentik, Keycloak, Authelia or Zitadel.

How it works

A small daemon on each device watches the Claude Code files and sends new lines to your server. The server stores them in Postgres and serves the dashboard.

Install

macOS and Linux

curl -fsSL https://get.usebraid.dev | sh
braid login https://braid.example.com
braid install

Or with Homebrew: brew install usebraid/tap/braid. The script installs to ~/.local/bin. It does not use sudo.

Windows

Download the zip from the release page and follow the manual steps.

Server (Docker)

docker pull ghcr.io/usebraid/braid-server:latest

The image is built for amd64 and arm64. The docs have a Compose file.

Verify

Releases are signed with cosign. Check the checksum file:

cosign verify-blob \
  --bundle checksums.txt.sigstore.json \
  --certificate-identity https://github.com/usebraid/braid/.github/workflows/release.yml@refs/heads/main \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  checksums.txt

Self-hosting

You run the server and the database. The docs cover Docker Compose, an external Postgres, OIDC setup, reverse proxies and backups.
