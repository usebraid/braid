# Contributing

- **DCO:** sign off every commit with `git commit -s` (`Signed-off-by:` line). There is no CLA.
- **Conventional Commits:** `feat`, `fix`, `chore`, `ci`, `build`, `docs`, `refactor`, `test`, `perf`; breaking changes with `!`. Versions and changelog are generated by release-please (SemVer, `0.x` until 1.0).
- **Checks:** run `scripts/check.sh` before every commit (gofmt, vet, golangci-lint, govulncheck, SPDX headers, gitleaks, tests with Postgres via Docker). Install the hooks with `lefthook install`; never skip them.
- Every source file starts with `SPDX-License-Identifier: AGPL-3.0-or-later`.
