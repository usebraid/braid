# Braid band

Draws one line above the Claude Code prompt: this session's cost, today's usage across your devices and the Braid sync state. It adds no skill, command, agent or model-facing hook, so it costs no tokens. It only runs `braid stats --json`, so the `braid` CLI must be on your PATH and the device logged in.

See https://github.com/usebraid/braid for source and docs.
